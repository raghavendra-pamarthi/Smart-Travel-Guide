# Smart Travel Guide image policy

- Priority city attractions use place-specific Wikimedia Commons images.
- Imported/general catalogue entries never receive a generic Taj Mahal, Goa, Kerala, or other unrelated fallback image.
- When a verified source image cannot be found, the UI shows **Photo not available** and exposes the source page when possible.
- City cards open the full city collection (`/user/search?city=...`) rather than only the city record.
- Priority coordinates are stored as curated coordinates; selected Visakhapatnam/Vijayawada/Tirupati coordinates were corrected using OpenStreetMap/Wikidata/official sources where available.
